# 楊梅高中圖書館 3D 互動探索島 V2.0

以 Vite、Three.js 與 JavaScript ES Modules 製作的雙層圖書館探索網站。無登入、無資料庫，學習紀錄只存於目前瀏覽器。

## 本機執行

需要 Node.js 22.12+（本次驗證為 Node.js 24.19.0）與 npm。

```sh
npm ci
npm run dev
```

開啟 Vite 輸出的網址。正式建置：`npm run build`；預覽：`npm run preview`。雲端沙箱若無法使用預設 npm 快取，可執行 `npm ci --cache /workspace/.npm-cache`。

## 操作手冊

- 拖曳場景旋轉、滾輪縮放；手機單指旋轉、雙指縮放／平移。
- 左側 1F／2F 切換樓層；空間目錄或 3D 物件可點選並聚焦。樓梯的資訊卡可前往另一層。
- 完整建築、樓層展開、俯視、室內探索與 2D／3D 對照可切換；工具列可返回全景、鳥瞰、自動旋轉、日夜、標籤、全螢幕。展開距離可調。
- 「開始自動導覽」依固定站點巡覽，可暫停。語音須瀏覽器支援 Web Speech API，語音與全螢幕須使用者操作，受裝置權限限制。
- 選取資訊檢索區或新書展示區，開啟關鍵字、ISBN／書名查詢。所有三筆書目均為**虛構教學示範，非學校真實館藏**，ISBN 亦僅為示範字串。
- 選取事務機器，試算影印／列印／掃描費用；每頁黑白 2 元、彩色 6 元、掃描過卡免費，均需自備餘額 10 元以上悠遊卡。
- 選取借還書櫃台啟動六步驟借書模擬。地面虛線示意連結各站，並非經現場測量的可行走路徑；步驟視窗可關閉以觀察場景，重新開始會從入口重啟。最後須勾選模擬學生證才能完成。
- 「利用教育」提供 PDF 全文館規、Q01～Q11、分類／關鍵字搜尋與朗讀、7 題測驗及原始教材下載。
- 「新生探險」有 6 關，每關 100 積分；全部完成獲得探索達人徽章。書庫任務須先探索一樓樓梯；測驗須全對。
- 「我的學習」支援暱稱、探索紀錄、任務、分數、錯題、時間、JSON／CSV 匯出、列印與清除重來。探索時間以 10 秒記錄，最後不足 10 秒不計。
- 設定含全螢幕、音效、裝置、版面、語言、字體與效能，另可調速度。偏好保存於 localStorage。英文為明確標示的預留項目，未提供英文翻譯。音效在完成任務時播放。

## 資料來源與建模界線

已完整讀取使用者上傳的《新生利用教育說明資料.pdf》（2 頁），保存於 `public/materials/`，並以其為館規依據。PDF 內文作為教材資料使用。

兩張 1F／2F 配置圖以**對話內嵌圖片**提供，可檢視但未取得原始 PNG 二進位檔。本專案依可見圖面人工整理標準化相對座標，並非依現場尺寸測量；不得宣稱精確建築重建。檢視用 2D 圖是同一份資料的重繪示意，**不是原始圖片**。

圖片上方為座標北、右側為東。平面圖左上 `(0,0)` 到右下 `(1,1)`；3D 對應為 `x=(u-.5)*width`、`z=(v-.5)*depth`。未鏡像或旋轉資料。`src/data/layout.js` 提供尺寸（預設 40 × 22 示意單位）與轉換函式；層高是場景示意值。

一樓保留西北討論室、SDGs／平板車、中央閱讀與雜誌區、三組曬書桌、新書展示區、東北特藏區、資訊檢索、東南辦公室與其西側櫃台、東南樓梯。二樓北側十排直向書架、北側座位、中央六組閱讀桌、兩端討論室、東側螢幕／樓梯／儲物室、南側兩組閱讀桌。

### 配置驗證

1. 選擇樓層，切換「配置驗證」，場景轉俯視。
2. 預設顯示重繪資料並半透明疊合至模型上；可調透明度。
3. 可用「載入原始配置圖」選擇對應 PNG／JPEG，在本次工作階段比較；不會上傳伺服器。原始圖未包含於專案。
4. 點選區域，調整 X／Y，綠／橘範圍分別代表選取或調整後範圍與原始資料框；可還原或匯出 JSON。調整僅留於本次工作階段，維護者應審核匯出資料後更新 layout 原始檔。
5. **不會自動辨識圖片或判定配置誤差**；同源資料的對照不能作為準確性證明，需人工對照原圖／現場校正。

## 原始碼結構

- `src/data/floor1-layout.js`、`floor2-layout.js`：穩定 ID、分類、尺寸、座標、mapBounds 與互動定義。
- `src/scene.js`：程序化模型、OrbitControls、Raycaster、相機動畫、批次書籍模型。
- `src/main.js`：介面與互動、學習狀態、設定及匯出。
- `src/data/library-content.js`、`faq-data.js`、`quiz-data.js`、`tour-paths.js`：教學內容與導覽。
- `tests/layout.test.js`：配置、座標、教學資料與計分測試。
- `tests/browser.mjs`：實際 Chromium 操作測試。

## 已驗證

- `npm test`：4 項測試通過，含區域範圍／唯一 ID、關鍵相對位置、十排書架與六組閱讀桌、雙向座標轉換、11 題 FAQ、計分與費用。
- `npm run build`：正式產物建置成功，使用相對資產路徑支援 GitHub Pages 子目錄。
- `node tests/browser.mjs`：系統 Chromium／SwiftShader 實際 WebGL 渲染、桌面與 390px 手機版、樓層／地圖點選、FAQ 搜尋、費用試算、學生證步驟、全對計分、設定與重新整理後保存，無 pageerror。
- 瀏覽器測試預設需先啟動 `npm run dev -- --port 5173`，本機預設 Chromium 位於 `/usr/bin/chromium`；可用 `CHROMIUM_PATH` 指定其他路徑。CI 使用 Playwright 安裝的 Chromium。`BASE_URL` 可指定正式網站網址，預設為本機 5173。

## GitHub Pages 部署

已提供 `.github/workflows/pages.yml`：main push 或手動執行 → npm ci → 測試 → build → Pages artifact → deploy。

1. 將專案提交並推送到 `isvincent/3DLibrary1` 的 main。
2. 到 GitHub repository → Settings → Pages → Source 選 **GitHub Actions**。
3. 在 Actions 執行「Deploy library to GitHub Pages」。
4. 以成功 deployment 回傳網址開啟，再確認資產、PDF、樓層、學習流程與手機。

2026-10-26 接續驗證：程式、README 與教材均保留；四項單元測試、正式建置與桌面／手機尺寸 Chromium 互動測試通過。已確認 GitHub 帳號具有管理與推送權限。部署完成後，Actions 的 verify 工作會針對正式網址執行相同瀏覽器測試，並檢查教材 PDF；請以該工作的實際結果判定部署驗收狀態。
